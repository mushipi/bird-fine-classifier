# Perch蒸留によるカモ細分類モデル強化 — 実験レポート

作成: 2026-06-11 / 対象: bird-fine-classifier（カモ10種・BirdNET後段・3秒固定チャンク）
実行環境: mainPC（RTX3060Ti, `~/Scripts/bird-fine-classifier`, 本体`.venv` torch2.6+cu124）

---

## 0. 要旨（結論先出し）

- **「Perch を教師にした知識蒸留（KD）」がモデル強化の確かなレバーだと統計的に確定した。**
  事前学習なしの素のCNNで **録音単位 f1 0.45 → 0.60（+0.148, 95%CI[+0.084,+0.211]＝有意）**。
- 自作AST（強い事前学習済み）への蒸留でも **0.826 → 0.851** と教師を超えたが、ASTは天井近くで
  伸びしろが小さく、+0.025 は 231録音の解像度では**有意化しなかった**（効果は本物だが埋もれた）。
- 評価は一貫して **録音単位 macro-F1 + 録音クラスタ bootstrap CI**（チャンク単位の点推定は使わない）。
- **【2026-06-13 重大訂正】** test拡大Cv2の honest 再評価で、**運用モデル `ast-duck-C-kd-soup` の従来値
  (0.871/0.910) はテストへの学習リーク(最大45%)による膨張**と判明。リークフリー159録音での honest は **≈0.787**。
  クリーン再学習した **`Cv2BASEsoup`(蒸留なし) が 0.897 で現行を +0.110[+0.042,+0.172] 有意に上回る**。
  伸びの主因は**データ拡大とクリーンsplit**で、蒸留ではない（**AST最終soupでは KD が乗らず clean では base>KD 有意**）。
  → 詳細 **§13**。KDの価値は「弱い生徒(素CNN)・seed分散低減」に限定という理解に更新。

## 1. 背景と行き詰まり

自作ASTライン（HF Trainer で fine-tune）は test 録音単位 f1 ≈ 0.83 で頭打ち。別系統の
Perch2.0 凍結埋め込み＋線形プローブも同水準。直近の総点検で確定していた2つの壁:

- **モデル選定が運任せ**: 同設定でも seed/early-stop で大きく振れ、点推定の優劣は小test では区別不能。
- **同一埋め込み上のプローブ強化は枯れた**: 正則化（weight_decay / C）は無反応。一般レシピ強化
  （SpecAugment / AudioMAE / focal）も既に不採用。

→ 「同じ表現でプローブを強くする」は限界。**別系統の知識を注入する＝蒸留**へ。

## 2. 前段の検証（強化の前提固め）

### 2.1 Perch線形プローブ 正則化スイープ（A→B）
linear / mlp / sklearn を test録音単位f1で横並べ。**champion=sklearn C0.01 で 0.827**。
**torch線形の weight_decay は完全無反応**（wd 0〜1e-2 が同一値＝同一解に収束）。正則化軸は枯れたと確定。

### 2.2 P1 Foundation 比較（3秒固定下）
| 埋め込み | best arm | test録音単位f1 | AUROC |
|---|---|---|---|
| Perch raw32k | mlp wd0 | **0.8308** | 0.967 |
| Perch processed | sklearn C0.01 | 0.8269 | 0.981 |
| BirdAVES(mean) | sklearn C0.1 | 0.6459 | 0.933 |

**Perch >> BirdAVES**（差0.18超）。3秒制約下の「Perch凍結＋軽量プローブ」天井 ≈ 0.83。

## 3. データ regime の重大な訂正

蒸留の実装中に判明: **現 `data/splits` は v15 学習時とは別データセット**だった。

| | v15時代 | 現在 |
|---|---|---|
| label_map | 11クラス（10カモ+other） | 12クラス（カルガモ/カワアイサ含む） |
| test録音数 | 81 | 231 |
| 変更 | — | commit `4cea661` で splits 全面改訂 |

現 splits の実体は **10カモちょうど**（"other"行もカルガモ/カワアイサも無し。それらは `data/ood/` に分離）。
→ KD実験の regime を **Option C（現の大きい splits・10クラス・ラベル順＝教師順）** に確定。
231録音で解像度が高く、教師probaとも整合する綺麗な統制比較になる。

---

## 4. 手法: Perch → 生徒 への知識蒸留

- **教師**: Perch プローブ **複数arm平均**（linear+mlp+sklearn の proba を平均）。
  train のソフトラベルは **録音単位 5-fold OOF**（過学習した過信ラベルを避ける）。
- **クラス空間**: Perch 12ラベル（operative 10カモ）→ 生徒の10カモ列へ **種名で写像**、行正規化。
- **損失**: `loss = CE + λ·T²·KL( softmax(teacher/T) ‖ log_softmax(student_logits[:10]/T) )`。
  カモ10列のみ・教師ありサンプルのみ（`has_teacher` マスク。今回は全カモがカバー）。
- **評価規律**: 録音単位 macro-F1（softmax平均集約）＋ 録音クラスタ bootstrap CI。CIが0を含む差は「差なし」。

## 5. 結果①: 自作AST への蒸留

同 regime・同 seed42 で base（蒸留なし）と KD を学習し、録音単位（n=231）で比較。

| モデル | 録音単位 f1_macro | 95%CI | eval_loss |
|---|---|---|---|
| C-base（蒸留なし） | 0.8259 | [0.755, 0.879] | 2.229 |
| **C-kd（蒸留）** | **0.8510** | [0.786, 0.899] | **1.672** |
| teacher（Perch・参考） | 0.8304 | — | — |
| ensemble α0.4（参考） | 0.8514 | — | — |

- **KD は教師Perch(0.830)を超え、アンサンブル(0.851)と同水準**（生徒が教師超え＝良い蒸留）。
  eval_loss も大幅低下＝過信が抑えられキャリブレーション改善。
- **ただし KD−base = +0.0251, 95%CI[−0.0215, +0.0790] → 0を含む＝統計的に有意でない。**
  原因はASTが天井(≈教師0.83)近くで伸びしろが小さいこと。231録音の解像度に埋もれた。
- 補足: Phase0 ゲートで旧v15(別regime)を現testで測ると0.747と低く出たが、これは regime 交絡。
  同条件の新規ベースラインは0.826で教師とほぼ互角＝「AST≈Perch互角」が正しい絵。

## 6. 結果②: 素のCNN への蒸留（手法の有効性検証）

AST は天井近くで効果が埋もれた。そこで **伸びしろの大きい素の小CNN**（from-scratch, 0.39M params,
Conv×4+GAP+FC）に同じ KD を適用。dataset・教師proba・KD損失・評価はすべて流用、生徒だけ差し替え。

| モデル | 録音単位 f1_macro | 95%CI |
|---|---|---|
| base-CNN（蒸留なし） | 0.4498 | [0.383, 0.507] |
| **KD-CNN（蒸留）** | **0.5977** | [0.521, 0.662] |
| teacher（参考） | 0.8304 | — |

**KD−base = +0.1478, 95%CI[+0.0843, +0.2112] → ★有意（CIが0を除外、下限+0.084）**
録音内訳: KD正/base誤=**53**, KD誤/base正=13, 不一致 107/231（net +40録音）。
chunk単位 val も 0.478→0.590（+0.111）。

→ **「Perchを教師にした蒸留は本当に効く」を統計的に初確認。**
弱い生徒では効果量が大きく、231録音でも明確に有意。AST の +0.025（非有意）も
**同方向・同機構の本物の効果**だったと遡って裏付く。素の0.39M CNN が教師との差を約37%埋めた。

## 7. 総合結論

- **KD-from-Perch ＝ プロジェクトの確かな強化レバー（有効性は統計的に確定）。**
- **実用モデルとしての最良は AST KD 版（録音単位 0.85）**。CNN(0.60)は検証用で実用ではない。
- AST 側で「有意」を主張するには **test拡大** または **複数seed** が必要（効果は本物だが小さい）。

## 8. CNN を試験台にした KDハイパラ・グリッド

CNN（~3分/run・効果が大きく測れる）で λ∈{0.5,1,2,4}×T∈{1,2,4} を探索。
val 録音単位f1で選定（test選択バイアス回避）、test を報告。

| 構成 (λ,T) | val_f1 | test_f1 | Δtest vs base |
|---|---|---|---|
| base (λ0) | 0.482 | 0.450 | — |
| **λ1, T2**（best-by-val） | **0.681** | 0.598 | **+0.148** |
| λ1, T1 | 0.655 | 0.658 | +0.208 |
| λ2, T1 | 0.636 | 0.561 | +0.111 |
| λ2, T4 | 0.631 | 0.585 | +0.135 |
| λ0.5, T1 | 0.607 | 0.578 | +0.128 |
| λ1, T4 | 0.576 | 0.615 | +0.165 |
| （残り6構成も全て +0.048〜） | | | + |

**読み:**
- **全12構成が base を上回る（Δ +0.048〜+0.208）＝KDはハイパラに頑健に効く。**
- 甘い所は **λ≈1・T≈1〜2**。λ=4（KD過重でCEを溺れさせる）/ T=4（柔らかすぎ）は弱まる。
- best-by-val = **λ1,T2**（＝結果②の設定。+0.148, 95%CI[+0.084,+0.211]＝有意）。最初の設定が既に最適域。
- val/test順位の食い違い（λ1,T1がtest最高0.658だがval2位）は231録音のノイズ。地形（全KD>base・λ1・T1〜2最良）は頑健。
- **ASTへの含意**: AST蒸留で使った λ1,T2 は最適域そのもの。**ASTでλ/Tを振っても +0.025 が大きく変わる見込みは薄い**
  （ASTの限界はKDレシピでなく天井近くの伸びしろ）。AST有意化は test拡大/複数seed が筋。

## 9. 多seed + soup: AST でも KD を統計的に有意化

「単発では非有意」だった AST KD を、**多seed（42/1/2）＋ model soup（重み平均）**で固めた。

**(1) seed をまたいだ一貫性**（録音単位 test f1）:
| seed | base | KD | KD−base |
|---|---|---|---|
| 42 | 0.826 | 0.851 | +0.025 |
| 1 | 0.825 | 0.858 | +0.033 |
| 2 | 0.801 | 0.825 | +0.024 |
| 平均 | 0.818 | 0.845 | **+0.027** |
| SD | 0.011 | 0.014 | **0.004** |

→ **KD>base が 3/3 seed**。差の SD はわずか 0.004（絶対値SDより遥か小）＝**KDは seed の引きに依らず安定して +0.027 を上乗せ**。「運任せ」を均せた。

**(2) model soup での有意化**:
| | 録音単位 f1 | 95%CI |
|---|---|---|
| base-soup（3seed平均） | 0.8133 | [0.746, 0.867] |
| **KD-soup（3seed平均）** | **0.8714** | [0.812, 0.918] |

**KD−base = +0.0581, 95%CI[+0.018, +0.108] → ★有意（CIが0を除外）**。
KD-soup 0.8714 は個々のKD最良(0.858)も超え、**過去最高のAST**（教師0.83も大きく上回る）。

**結論**: 多seed soup で **AST における KD の効果を「本物かつ統計的に有意」に格上げ**。
**昇格候補 = `models/ast-duck-C-kd-soup`（0.8714）**。

## 11. カルガモ壁の正体 — Perch2.0本体でも分離不能（戦略確定）

「カルガモ↔マガモの混同は我々のデータ/プローブの限界か、音響的に本質的か」を直接検証。
**Perch2.0のネイティブeBird分類ヘッド**（14795クラス・カルガモ専用クラス `spbduc` 保持）を
実物のカルガモ/マガモ各30録音に当てた（`tools/perch_native_confusion.py`）。

| | カルガモ録音 | マガモ録音 |
|---|---|---|
| 自種 vs 相手 2値勝率 | **0/30** | 30/30 |
| 全クラス argmax=自種 | **0/30** | 18/30 (0.60) |
| argmax先 | mallar3=12, brebul1=12… | mallar3=18… |

**結論**: 世界最大級の学習・専用クラス持ちの Perch2.0 **でさえカルガモを1件もカルガモと認識できず、
全てマガモ側に吸収される（非対称崩壊）**。→ **カルガモ壁は音響的に本質的**（交雑する近縁・声がほぼ同一）。
我々のモデル/データの問題ではない。

**戦略確定**:
- 音声でカルガモを種同定するのは**誰がやっても無理＝精度向上は死に筋**（Phase2の分類アプローチを撤回）。
- 正解 = **複合クラス ≒ 属名出力**。音響的に割れないペアは「**マガモ属(Anas)複合**」or「マガモ/カルガモ」
  として出す。最頻種カルガモ（国内観察3位）を**捨てずに誠実に表現**できる（弾く＝カルガモ観察を全捨て）。
- Phase2 を「精度で殴る」から「**割れないペアを属/複合クラスに束ねる出力設計**」へ転換。
- 副次: カルガモOOD録音の 12/30 がヒヨドリ(brebul1)にargmax＝`data/ood_processed`の品質低（Phase3で要再生成）。

**実装（複合クラス出力, 再学習ゼロ）**: in-dist混同行列(C-kd-soup)を確認 → **10種内に構造的混同ペア無し**
（弱種は小標本振れ）＝**必要な複合はマガモ/カルガモの1個のみ**。`species_taxonomy.yaml` に
`display_groups`（Mallard→「マガモ/カルガモ」, slash分類群）、`predict.py` で出力を和名/学名＋複合へ解決
（`species_master` の ja/sci、複合override）。10種はそのまま個別、Mallard出力＝複合（カルガモ受容）。
「カモ科 sp.」後退（低信頼）は次段（信頼閾値の要キャリブレ）。

## 13. test拡大Cv2: リーク発覚と honest 再評価（2026-06-13）

§9/§10の昇格(Cprod=`ast-duck-C-kd-soup`)後、残課題(B)「評価解像度＝test録音数不足」に着手。
B級worldwide収集→**全データ再split**→**base/KD×3seed再学習→soup**(Cv2)。test録音 **69/231→289**(3743chunk),
弱種support改善(ヒドリ7→**35**, 最小ウミアイサ11/キンクロ17)。評価ツール `tools/probe_sweep/soup_ci.py`(teacher非依存CI)。

### 13.1 リーク発覚
拡大test**全体**(n=289)では Cprod0.910≈Cv2BASE0.908≈Cv2KD0.894 で全ペア差なし＝一見「現行維持」。
しかし **Cprod は旧splitのtrainで学習**。Cv2の再splitで Cprodの学習録音が test に混入:
**旧(train∪val) ∩ Cv2-test = 130/289 = 45.0%**(旧train106+旧val24)。整合性 Cv2-train∩Cv2-test=0(Cv2はクリーン)。

### 13.2 honest 再評価（リークフリー159録音 = 3モデルとも未学習）
| model | 録音f1 | 95%CI | 対Cprod差(同一録音ペア) |
|---|---|---|---|
| **Cv2BASEsoup**(蒸留なし) | **0.897** | [0.704,0.951] | **+0.110 [+0.042,+0.172] 有意** |
| Cv2KDsoup(蒸留) | 0.822 | [0.625,0.890] | +0.034 [−0.051,+0.108] 差なし |
| Cprod(現行運用) | 0.787 | [0.613,0.843] | — |

- KDsoup − BASEsoup = **−0.076 [−0.164,−0.015] 有意**（clean では蒸留なしが上）。

### 13.3 結論
1. **運用モデルの実力はΔ≈0.12過大評価**(0.910→honest0.787)。**昇格判定は必ず候補が未学習の録音で**。
2. **Cv2BASEsoup が現行を有意超え**。主因はデータ拡大(1020→1288録音)＋クリーンsplitで、**蒸留ではない**。
3. **天井近いAST最終soupではKDが乗らない**(clean有意で base>KD)。KDの価値は§6の弱い生徒(素CNN)・seed分散低減に限定。
4. **判定: Cv2BASEsoup を新運用へ昇格(別ステップ)** ＝ 運用名登録→`species_taxonomy.yaml` stage2_model差替→
   **OOD energy閾値の再キャリブレ必須**(モデル変更でenergy分布が変わる, 現2.717は旧モデル用)。本コミットは記録の先行。
